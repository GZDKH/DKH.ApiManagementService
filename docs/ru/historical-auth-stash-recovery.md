# Архив: восстановление stash авторизации API management

Локальный stash `049cf672629f4db2e83bdef3558f6928ee74648a` сохранён как
родитель этого коммита вместе с родителями индекса и неотслеживаемых файлов.
Он содержит прежнюю миграцию правил Codex на основе коммита авторизации
`6e4dca81eae62fadc8aaa108935c38ef684f82f1`, которого нет в истории текущего main.

Исторические код авторизации и правила не применены к текущему дереву. Старая
конфигурация отключает проверку issuer, audience и HTTPS metadata и не одобрена
для развёртывания. Архив не является проверкой безопасности или подтверждением
работы прежнего поведения с текущим main.

Изменения можно изучить через `git diff <stash>^1 <stash>`, а других родителей —
через `git show <stash>^2` и `git ls-tree -r <stash>^3`. Перед использованием
содержимое нужно проверить. Исходный stash остаётся локально.

Squash-слияние исключит исторических родителей. До squash или удаления исходной
ветки нужно отдельно сохранить исходный stash и его родителей.
